# ♡ My Little Journal

**A soft little corner of the internet to write, remember, and preserve your everyday moments.**

My Little Journal is a personal digital diary designed to make journaling simple, peaceful, and beautiful. It provides a private space where users can write daily entries, save memories, add photos, and keep personal letters.

🌷 **Live Website:** [My Little Journal](https://my-little-journal-phi.vercel.app/)

---

## ✨ Features

- 📝 **Daily Journaling:** Write and save personal thoughts and everyday experiences.
- 💌 **Letters:** Create and preserve personal letters.
- 📸 **Photo Memories:** Add photos to make journal entries more meaningful.
- 📚 **Journal Archive:** Access and revisit previous entries.
- 📅 **Calendar View:** Keep track of journal entries by date.
- 🔐 **Private Authentication:** Secure personal journal access.
- ⚙️ **Settings:** Manage personal journal preferences.
- 🎀 **Pastel UI:** A soft, minimal, and aesthetically pleasing interface.
- 📱 **Responsive Design:** Designed for both desktop and mobile screens.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | Frontend development |
| TanStack Router | Client-side routing |
| Supabase | Authentication, database and backend services |
| CSS | Styling and responsive UI |
| Vercel | Website deployment |

## 📂 Main Sections

- **Home:** Your personal journaling space.
- **Write:** Create new journal entries.
- **Archive:** Browse saved journal entries.
- **Calendar:** Explore memories by date.
- **Letters:** Write and store personal letters.
- **Settings:** Manage your journal preferences.

## 🎨 Design Philosophy

My Little Journal focuses on a calm and comfortable journaling experience.

- Soft pastel-inspired aesthetics.
- Clean and minimal layouts.
- Simple navigation.
- Personal and distraction-free writing space.

## 💭 Why I Built This

I wanted to create a personal digital space where everyday thoughts, little achievements, memories, and feelings could be preserved.

My Little Journal is a small project built with the idea that even the simplest moments deserve to be remembered.
